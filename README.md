# The Amazon Fund and Deforestation

Seminar paper for *Forschungsprojekte zur Empirischen Wirtschaftsforschung* (LMU Munich, summer 2021).

The paper asks whether projects financed by the [Amazon Fund](https://www.amazonfund.gov.br/en/home/) (Fundo Amazônia) reduced deforestation in Brazilian Amazon municipalities. It uses a municipality-by-year panel and estimates fixed-effects, first-difference and difference-in-differences models. Controls include indigenous land, agricultural land use and commodity prices.

**Report:** [`report/The_Amazon_Fund.pdf`](report/The_Amazon_Fund.pdf) (22 pages)

## Repository layout

| Path | Contents |
|---|---|
| `code/analysis.R` | Full analysis: data cleaning, panel construction, regressions, plots |
| `data/` | Input data read by the script (see below) |
| `report/` | LaTeX source (`The Amazon Fund.tex`, `reference_Pareto.bib`), TikZ figures generated by the script, and the compiled PDF |
| `figures/` | Exploratory plots: treatment groups, deforestation and cashflows for selected municipalities |

## Data

| File(s) | Description |
|---|---|
| `terrabrasilis_legal_amazon_*.csv` | Yearly deforestation per municipality (INPE PRODES via [TerraBrasilis](http://terrabrasilis.dpi.inpe.br/)) |
| `fundo_amazônia_projekte_cashflows.xlsx`, `projekte_treatments.xlsx` | Amazon Fund project disbursements and the resulting municipal treatment assignment |
| `Landwirtschaftlich verwendete Flächen.xlsx` | Agricultural land use per municipality (IBGE) |
| `Commodity_price.xlsx` | Commodity price series |
| `Gesammtfläche von Gemeinden.xls` | Municipality area within the Legal Amazon |
| `TI_*.dbf`, `Final_Data_for_Indigenous_Lands.xlsx` | Indigenous lands per state |
| `updated_means.xlsx` | Treatment/control group means used for the plots |

Raw IBGE spreadsheets and the literature PDFs used during the project are not included. The references are listed in the report bibliography.

## Running it

Requires R with `tidyverse`, `readxl`, `foreign`, `plm`, `sandwich`, `lmtest`, `fastDummies`, `writexl`, `rio`, `geobr`, `sf`, `tikzDevice`, `texreg` and `xtable`.

```sh
Rscript code/analysis.R          # run from the repo root
cd report && latexmk -pdf "The Amazon Fund.tex"
```

## Caveats

- `code/analysis.R` is the exploratory script as written in 2021. Variable names are partly German (`Gemeinde` = municipality, `Fläche` = area, `Abholzungen` = deforestation) and it was developed interactively. For example, line 48 uses `means`, which is only loaded at line 1298, so it will not run cleanly top to bottom.
- The only change since 2021 is that file paths are now relative to the repo root. I have not re-run the full script. The final `geobr` map section downloads data at run time.
- The script contains a block that replaces missing values with municipality means. It is marked `DO NOT USE WITHOUT CHECKING` in the code.
